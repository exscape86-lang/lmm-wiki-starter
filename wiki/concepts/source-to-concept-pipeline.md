# Source to Concept Pipeline

Source to Concept Pipeline은 원본 자료를 곧바로 “내 지식”이라고 부르지 않고, 반복적으로 쓸 만한 생각만 concept로 승격하는 방식입니다.

## 기본 흐름

```text
source 수집 → 핵심 요약 → concept 후보 → concept 승격 → daily에서 연결 기록
```

## 좋은 source 노트

- 원문 링크가 있습니다.
- 내가 왜 저장했는지 한 줄 요약이 있습니다.
- 연결할 concept 후보가 있습니다.

## 좋은 concept 노트

- 여러 source에서 반복됩니다.
- 내 프로젝트나 의사결정에 다시 쓰입니다.
- maturity가 `stub → developing → stable`로 올라갑니다.
